# ScoreTab CS2

Рабочая спецификация по палитре из ТЗ. Предоставленная эмблема ST CS2 используется в системной иконке и в шапке приложения. Справа от неё расположены название с янтарным акцентом CS2 и подпись «by gearbarium».

| Роль | Цвет |
| --- | --- |
| Фон | `#050B12` |
| Панели | `#0A1520` |
| Карточки | `#11212E` |
| Основное действие | `#FFB02E` |
| Нажатое действие | `#D88B18` |
| Фокус | `#FFD184` |
| Основной текст и счёт | `#F1F7FB` |
| Вторичный текст | `#9CAEBB` |
| Контур | `#526A79` |
| Разделитель | `#243744` |

Inter с кириллицей. Счёт и название команды остаются на одной позиции при смене сторон. Ввод раунда располагается под табло. Протокол открывается отдельным представлением. Служебные операции находятся в свёрнутом разделе.
