# ScoreTab CS2

Офлайн-протокол матчей Counter-Strike 2 для Windows и Android. Учёт раундов, автоматический счёт, смена сторон, овертаймы и история матчей.

**Скачать:** [последний релиз](https://github.com/gearbarium/ScoreTab-CS2/releases/latest). Для Windows распакуйте ZIP и запустите EXE. Для Android установите APK.

Экспорт в Excel, CSV и JSON. Папка для выгрузки задаётся в настройках.

Сборка из исходников: `cargo build --release --locked` в `windows`; `.\gradlew.bat :app:assembleDebug` в `android` (JDK 17, Android SDK 35).
